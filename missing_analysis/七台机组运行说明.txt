从项目根目录运行：
python -m unittest discover -s missing_analysis -p test_seven_units.py -v
python missing_analysis/seven_units.py all --workers 3

默认输出 missing_analysis/seven_units_v1。
优先打开 查看结果.html：只是本地SVG链接索引，不是HTML绘图。
每台机组每个K只保存时间条带、代表分布、转移矩阵三张SVG。
七台×K=2—6×三张图，共105张；按机组/K分目录，避免混放。
类别数比较.csv 提供全部35个模型指标；分析说明.txt 提供结论及边界。
其余数值结果集中在_data，正常浏览无需打开。

all 可从已完成的测点扫描和候选K恢复。
prepare / evaluate / report / verify 可分别执行。
仅重绘：python missing_analysis/seven_units.py report
协议改变必须使用新的 --output 目录；原始CSV保持只读。

范围：各自选取点表顺序；燃料组分仅CH4，保留密度与热值。
GARD每台30测点，其他每台23测点；全时段、上海时间自然日。
五十个0.01—1000秒对数箱加两个尾箱，无平滑；至少50个完整间隔。
每台机组单独学习共享类别，跨机组/跨K的类别编号与颜色不自动对应。
图中的蓝色C1不能自动解释为连续高频真值；要看该模型的代表分布。

数值接口：_data/<unit>/daily.csv 保存日期状态、源计数和各K标签/稳定性。
daily.npz 按 sample_id 保存52维counts/probabilities。
models.npz 合并保存全部初始化、日期扰动、代表日、标签、转移和打乱数值。
内部类别从0起、-1未分类；CSV类别从1起。
stability=-1未分类、0证据不足、1不稳定、2稳定。
analysis.json 保存逐K/逐类评价、逐测点/月占比、切换和删失可见段。
未分类日期不跨越连接；稳定性不足也不参与稳定标签转移图。
默认10初始化、20日期块子抽样/3初始化、500次逐测点标签打乱，与旧实验一致。

JQRD GT1历史已移动至missing_analysis/jqrd_gt1，按来源一致性检查复用。
没有历史缓存或来源改变时，新运行目录会正常扫描和拟合；历史模型不完整时重新拟合。
旧脚本保留；新入口复用其中经过测试的数学核心，不调用旧脚本的路径相关CLI。
_data/reproducibility.zip 保存新入口、所用核心、测试和依赖版本。
_data/manifest.json 保存协议、源清单、可能共享测点和环境；verification.json保存验证结果。
本地索引同时列出未通过的门槛及日期扰动ARI的10%分位数。
