# 固定深度学习模板的维护约定

本文件适用于dl_template及其全部内容。用户明确要求结构完全一致；未经用户明确修改此约定，不得调整以下固定结构。

## 不允许修改的结构

- 源码固定为config.py、data.py、model.py、train.py、evaluate.py、main.py，另保留本AGENTS.md。不得新增、删除、移动或重命名业务文件、子目录；不得增加utils、基类、注册器、插件系统或配置框架。
- 四个业务模块及职责固定：data负责导入、检查、划分、预处理和特征选择；model负责网络定义和创建；train负责训练、验证、最佳权重保存与恢复；evaluate负责预测和检验。不得跨文件搬迁这些职责。
- 固定公开函数及参数：prepare_data()；build_model()；train_model(model, train_loader, val_loader)；predict(model, loader)；evaluate(predictions, targets)；main()。不得重命名、增删参数或改变返回结构。
- prepare_data返回三个DataLoader和预处理状态字典；build_model返回模型；train_model返回已恢复最佳权重的模型；predict返回预测和目标两个Tensor；evaluate返回指标字典。
- main只按数据→模型→训练（含验证和最佳权重恢复）→预测→检验的顺序调用。入口固定为python dl_template/main.py。
- 所有可调参数集中在config.py，使用普通Python常量；不得增加YAML、命令行覆盖或环境变量覆盖。现有参数名称保持不变，确有任务需要时可以在此添加参数。
- 运行产物仅为config.CHECKPOINT_PATH指定的一份最佳权重；不默认增加日志、图、报告、预测文件或中间数据。Python自动缓存不属于业务源码，亦不得作为交付物。

## 允许修改的内容

- config.py：参数值；任务确有需要的新参数。默认CPU、种子17；设备必须显式配置。
- data.py：函数内部的数据读取、明确的清洗规则、列选择、划分策略、张量构造和预处理状态内容。时序数据应改为时间划分；图像等任务可替换DataLoader所用数据集，保持返回结构。
- model.py：网络类、网络层及build_model内的model = ...；任务需要时可以在本文件定义网络类。不得要求所有任务继承自定义通用父类。
- train.py：函数内部的criterion = ...、optimizer = ...、前向计算、损失计算及训练细节；模型选择依据只能来自验证集。
- evaluate.py：任务所需的预测计算和指标；指标字典的键可以随任务修改。
- 各模块可按必要程度增加本文件内的辅助函数或调整依赖导入，但不得增加新的公共调用阶段。main保持仅串联流程。
- 张量维度可以随任务改变，但必须由数据和模型显式约定；不得自动猜测、广播或静默变形来掩盖错误。

## 始终保持的行为

- 用户2026-10-21确认以其精简后的data.py为风格参考：顺序直写，每步单独命名，训练和验证显式分开；不增加演示数据分支、冗长注释或重复防御检查。文件/字段/设备等错误优先由底层库直接抛出，不捕获掩盖；保留避免静默形状广播和非有限损失等必要检查。此项优先于下文要求所有错误都附加阶段说明的旧约定。

- 初学者可读：普通函数、清楚命名、常规多行代码、简短中文注释。只实现当前任务需要的逻辑，不预建多任务切换分支。
- 路径、字段、空划分、形状或数值有问题立即报错，包含阶段和原因；不得吞异常、自动重试、自动换设备、静默删行或填值。
- 先划分再拟合预处理；拟合只使用训练集。预测和检验不参与训练、预处理拟合或模型选择。
- 验证与预测关闭梯度并使用评价模式；训练后恢复验证集表现最好的权重，再检验测试集。
- 不改写源数据，不自动接入项目现有实验。
- 修改后至少核验本次任务完整流程、最佳权重恢复、关键报错和训练/验证/测试隔离。检查用临时数据不留在本目录。

结构变更必须由用户明确提出；不能因“重构”“通用化”或实现便利自行突破本约定。
